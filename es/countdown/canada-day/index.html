El Día de Canadá (Canada Day) se celebra el 1° de julio y conmemora la Confederación canadiense el 1° de julio de 1867, cuando las provincias de Canadá, Nueva Brunswick y Nueva Escocia se unieron para formar el Dominio de Canadá. Se celebra con fuegos artificiales, conciertos y desfiles en todo el país.

Preguntas Frecuentes

¿Cuándo es el Día de Canadá?

El Día de Canadá es el 1° de julio cada año.

¿Qué se celebra el Día de Canadá?

Se celebra la Confederación de Canadá el 1° de julio de 1867, cuando las provincias se unieron para formar el país.

¿Es feriado el Día de Canadá?

Sí, el 1° de julio es feriado federal en Canadá.
