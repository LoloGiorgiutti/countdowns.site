Le 28 avril est le jour numéro 118 de l'année et se situe en semaine 18 du calendrier ISO. Ce compteur montre le temps exact jusqu'au prochain 28 avril. Le compteur se réinitialise automatiquement.

Questions Fréquentes

Dans combien de jours est le 28 avril ?

Utilisez le compte à rebours ci-dessus pour voir les jours, heures, minutes et secondes exacts jusqu'au 28 avril.

Quel jour de l'année est le 28 avril ?

Le 28 avril est le jour numéro 118 de l'année (hors année bissextile). Il tombe en semaine 18 du calendrier ISO.

En quelle semaine de l'année est le 28 avril ?

Le 28 avril tombe en semaine ISO 18 de l'année. C'est le 118e jour de l'année.

Le compte à rebours se réinitialise-t-il chaque année ?

Oui — lorsque le 28 avril arrive, le compteur se réinitialise automatiquement pour l'année suivante.

Le 28 avril est-il un jour férié ?

Cela dépend du pays. Utilisez le compte à rebours pour compter jusqu'au 28 avril.
